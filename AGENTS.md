# Memory study working instructions

This is the canonical working repository for the memory study. Read CONTEXT.md and the target cohort's DOCUMENTATION.md, CONTEXT.md and EXPERIMENT.md before changes. Keep executed evidence, software checks and proposed experiments distinct.

The released implementations supply the memory algorithms. AppWorld supplies tasks, applications, acting agent and evaluator. Document integration changes explicitly. Use actual configured models for live evidence; never substitute fabricated responses or hand-written lessons.

Historical source and evidence accessed through local/legacy and results are frozen private inputs. Do not mutate them or reuse their ledgers for new cohorts. E01-E15 and retained research outside this repository are out of scope. New work belongs here. Never commit local links, credentials, raw provider conversations, native stores, downloaded dependencies or evidence archives.

For MA01, follow adjacent/EXPERIMENT.md. No model runs have occurred for that cohort. The population is fixed before outcomes. Do not retune thresholds, swap tasks or selectively rerun conclusive failures to obtain a memory improvement. Real provider failures stop dispatch; operationally uncertain attempts remain inconclusive.

Use plain language, preserve attribution to upstream work and do not add assistant attribution. Do not use em dashes in user-facing writing.
