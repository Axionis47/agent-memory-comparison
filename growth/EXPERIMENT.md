# Executed memory mechanism cases

The AppWorld acting agent used task instructions and actual latest action/result to select historical knowledge before action decisions. Mem0 and RecMem used native search; ACE, Trace2Skill and GEPA supplied whole playbook, skill or strategy artifacts. A common Gemini tool-search call supplied keywords for SQLite FTS5 over current API definitions. The agent independently generated executable Python and could discover native documentation directly.

During the executed practice and integration cases, Mem0 and RecMem processed actual experience arrivals, ACE reflected and curated its playbook with a separate similarity analyser and post-update checks, and Trace2Skill evolved procedure files from trajectories. Actual actions, updates, exposures and official results were recorded. These cases do not isolate the causal contribution of each supplied item.

The separate GEPA retention diagnostic began with an empty strategy and made 14 candidate-testing task attempts. Its metric prioritised official completion, then actual API-call count. Native candidate acceptance was preserved. Candidate 2 was selected, persisted, reopened and frozen. Two later attempts received that instruction and two matching controls received empty memory, alternating order. The Venmo task passed with memory and failed without it; the file task passed in both conditions with 156 API calls. Training and selection cases overlapped, so these results do not establish held-out generalisation.

The executed provider settings were Gemini 2.5 Flash, temperature 0, thinking budget 0, Gemini Embedding 001 with 1536 dimensions, and 8,192-token context allowances. The RecMem recurrence configuration was six related arrivals, similarity 0.7 and episode-merge threshold 0.75. ACE similarity grouping used 0.90. Recurrence counts arrivals, not independent tasks.

The source audit found standalone simulated-password observations surviving the main learning-copy redactor. The separate GEPA diagnostic supplied an additional process-local repair; the original evidence was preserved. The published records exclude authentication values and raw observations. Truncation, watchdog stops and provider uncertainty were not scored as task failures.
