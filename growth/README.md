# Executed memory integration

The adapters in this directory connected released memory mechanisms to an AppWorld acting agent. The [executed case method](EXPERIMENT.md), [findings](../docs/FINDINGS.md) and [recorded actions](../evidence/cases.json) describe what was actually run.

The source contains the original dispatcher, including branches that were not completed. Those branches and configuration counts are not reported results. The dispatcher depends on private historical ledgers and is not a turnkey replay command for this public snapshot.
