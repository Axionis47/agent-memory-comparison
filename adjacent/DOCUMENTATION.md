# MA01 documentation contract

EXPERIMENT.md is the prospective protocol. CONTEXT.md records its stage. protocol.json binds the selected public tasks, source pins and prior-use audit; it is a planning manifest, not an accepted execution freeze.

Keep three distinctions explicit: intended learning opportunities versus actual learned content; consolidation versus retrieval; and software verification versus live model evidence. The task map is engineering context and never a hand-written lesson for the acting or consolidating model.

Report the consolidated/raw contrast separately from either condition versus no memory. Full-context exposure is not selective retrieval. Source-linked probe reachability is not useful-memory recall. Reviewer labels are not official grades. Compression and successful persistence do not establish improved task completion.

Use the existing Python/AppWorld/Vertex/Qdrant/SQLite/OpenTelemetry infrastructure. The new driver and adapters must remain experiment-specific. Preserve the prior study sources/results and E01-E15. One report, table, ledger and compressed evidence bundle serve this cohort. No copied project/archive trees or per-call reports.

Before any live evaluation, record actual shared practice, credential-safe learning units, native consolidation changes, immutable full-context renderings, equality checks and an execution freeze including all source/dependency/model/prompt/tool versions. Missing/inconclusive/excluded counts accompany every aggregate. No silent substitute model responses, replayed behavior, invented memories or repaired model outputs count as evidence.
